# Whisper Wake 기획안 (iOS 전용)

- 앱 이름: **Whisper Wake** (컨셉명: 속삭알람)
- 번들 ID: **com.addvalue.whisperwake**
- 플랫폼: **iOS 전용** (Swift / SwiftUI)
- 최종 갱신: 2026-11-16

## 1. 한 줄 정의
"삐빅 소리로 깨우는 알람"이 아니라, **은은한 배경음 위에 내 목소리(또는 AI 음성)로 오늘의 계획을 들려주며 깨우는 알람.**

## 2. 유사 앱 조사 (앱스토어·마켓 소개 페이지 기준, 2026-11)
| 앱 | 방식 | 한계 |
|---|---|---|
| Smastar (iOS) | 일정을 읽어주며 기상, 날씨·습관·할 일 브리핑 | 영어권 중심, 내 목소리 녹음 불확실 |
| Avo – AI Voice Alarm | 캘린더·메일·날씨·뉴스 연동, 유명인/캐릭터 목소리 | 한국어 불확실 |
| Alarm Clock: AI Morning Brief | 뉴스·날씨 중심 | 내 일정 중심 아님 |
| 모닝콜(iOS, 구독) | 전화처럼 걸려와 AI가 뉴스·날씨·응원 낭독 | 내 일정 낭독 아님, 구독료 |
| TalkClok (iOS, 유료) | 날씨·교통·캘린더 읽어주는 말하는 시계 | 감성·배경음 연출 없음 |
| Talking Voice Alarm / 말하는 목소리 알람 | 알람에 메시지 텍스트를 붙여 TTS | 단순 TTS, 배경음·내 목소리 없음 |
| 모티브알람 | 문구를 읽어야 꺼지는 알람 | 계획 안내 목적 아님 |

**결론:** "일정 읽어주는 알람"은 이미 존재. 다만 대부분 (1) 뉴스·날씨 위주, (2) 기계적 TTS, (3) 구독/클라우드 의존, (4) 한국어·감성 연출 부족. 여기가 틈새.

## 3. 차별화 포인트
1. **내 목소리 알람** – 전날 밤 30초 녹음 → 아침에 내 목소리로 계획 낭독. 가족 목소리도 가능.
2. **오프라인·무료 AI 음성 (Kokoro, Apache-2.0)** – 기기 내 합성, 서버비 0, 구독 불필요, 일정이 외부로 나가지 않음(프라이버시).
3. **사운드 연출** – 서서히 밝아지는 배경음 + 음성 구간 자동 덕킹 + 볼륨 램프업.
4. **입력 마찰 제로** – 공유 시트, 캘린더 자동 구독, 클립보드·스크린샷 인식, 카카오톡 공유, Siri 음성 명령으로 어디서든 한 번에 등록.
5. **스토리형 브리핑** – "좋은 아침이에요. 오늘은 일정 3개. 먼저 9시…" 톤 선택(차분/활기/코치).
6. **아침 경험 설계** – 중요도별 톤, 일정 직전 재알림, 습관 체크, 어젯밤의 나의 한마디, 위젯.
7. **한국어 우선 UX**, 확실히 깨우는 종료 장치(첫 할 일 말하기/탭).

## 4. 타깃
직장인·학생(루틴 형성), ADHD/계획 어려움 사용자, 시각장애·저시력(접근성), 미라클모닝 커뮤니티.

## 5. 일정 입력 방식 (iOS 구현안)
| 입력 | 구현 | 비고 |
|---|---|---|
| 직접 입력 / 내 목소리 녹음 | 앱 내 편집기, AVAudioRecorder | MVP |
| **공유 시트 등록** (메모·Safari·메일 등) | Share Extension → 텍스트 수신 → 파싱 → 확인 후 등록 | 자동 등록 금지, 미리듣기 후 확정 |
| **캘린더 자동 구독** | EventKit으로 오늘 일정 읽기, 알람 전날 밤/직전 갱신 | 캘린더 권한 필요. 변경 시 음성 재합성 |
| **클립보드 인식** | 앱 열 때 `UIPasteControl`/붙여넣기 버튼으로 가져오기 → 파싱 | iOS가 클립보드 접근 시 붙여넣기 허용 팝업을 띄움. 백그라운드 감시 불가 |
| **스크린샷 인식** | 사진 선택(PHPicker) 또는 공유 시트 → Vision OCR(VNRecognizeTextRequest, 한국어 지원) → 일정 추출 | 온디바이스, 사진 전체 접근 권한 불필요 |
| **카카오톡 "나에게 보내기"** | 카톡 메시지 길게 누름 → 공유 → Whisper Wake(Share Extension) | 카카오톡 대화 내용을 앱이 직접 읽는 공식 API는 없음. 공유 시트 방식이 현실적 |
| **음성 명령** | App Intents + Siri/Shortcuts: "Whisper Wake에 내일 9시 치과 추가해줘" | 단축어 앱에서 자동화(예: 블루투스·시간 트리거)도 가능 |
| 전날 밤 음성 입력 | Speech 프레임워크(STT, 온디바이스) → 일정 정리 | v1.2 |

**공통 파서:** "내일 9시 치과, 11시 팀회의" 같은 문장을 일정 단위로 분리(날짜·시간·제목). 규칙 기반 + 한국어 날짜 표현(모레, 이번 주 금요일, 오후 3시 반) 처리. 모호하면 사용자에게 확인. AI 보정은 선택(온디바이스 우선).

## 6. 아침 경험 기능
1. **중요도별 톤** – 중요 일정은 또렷하게 한 번 더, 일상 루틴은 부드럽게(속도·음량·반복 횟수 차등).
2. **일정 직전 재알림** – "30분 뒤 팀 회의" 알림을 음성으로(이어폰 연결 시 자동 낭독 옵션).
3. **습관 체크** – 브리핑 끝에 "물 한 잔 마셨나요?" → 탭/음성 응답 시 종료, 스트릭 기록.
4. **어젯밤의 나의 한마디** – 전날 밤 녹음한 응원 메시지를 브리핑 마지막에 재생.
5. **잠금화면·홈 위젯 / Apple Watch** – 오늘 읽을 내용 미리보기·수정, 워치 햅틱 기상.
6. **가족·연인 음성 메시지 알람** – 상대가 보낸 음성이 내 알람에 재생(v2, 서버 필요).
7. **확실히 깨우는 종료 장치** – 첫 할 일 말하기/탭, 스누즈 시 다음 일정 요약.

## 7. 기능 로드맵
- **MVP:** 알람(시간·반복) / 직접 입력 / 내 목소리 녹음 / 낭독+배경음 믹스 / 볼륨 램프업 / 로컬 저장
- **v1.1:** 공유 시트 등록, 캘린더 자동 구독, 클립보드 붙여넣기, 중요도별 톤, 일정 직전 재알림, 위젯
- **v1.2:** 스크린샷 OCR, Siri/App Intents 음성 명령, 카카오톡 공유 최적화, 밤 음성 입력(STT), 습관 체크·스트릭, 어젯밤의 나의 한마디
- **v2:** Apple Watch, 가족 음성 메시지 알람(서버), 프리미엄 배경음 팩

## 8. 기술 구조 (iOS)
- 언어/UI: Swift, SwiftUI. 최소 iOS는 Kokoro CoreML 변환본 요구 사항(검색상 iOS 18+ 언급) 확인 후 결정.
- **알람:** 최신 iOS의 AlarmKit(무음·집중 모드 대응) 우선 검토. 미지원 버전은 사전 생성 알림 사운드 + 로컬 알림 폴백. **알람 신뢰성은 최우선 검증 항목.**
- **TTS:** Kokoro-82M CoreML(온디바이스, INT8 약 80MB). 알람 시각에 합성하면 지연 위험 → **전날 밤/일정 변경 시 미리 합성해 오디오 파일로 캐시.**
- **오디오:** AVAudioEngine으로 배경음 루프 + 음성 믹싱, 덕킹.
- **연동 프레임워크:** EventKit(캘린더), Vision(OCR), Speech(STT), App Intents(Siri/단축어), Share Extension, WidgetKit, WatchKit.
- **내 목소리:** 녹음 파일 그대로 재생(음성 복제는 v2에서 동의·윤리 검토 후).
- **데이터:** 로컬 저장(SwiftData). 서버는 v2 전까지 불필요 → 개인정보 부담 최소화.

## 9. 핵심 리스크
1. **Kokoro 한국어 지원 불확실.** 일부 변환본이 한국어 프리셋을 표기하나 공식 확인은 못 함. 품질 낮으면 한국어는 "내 목소리 녹음" 중심 + iOS 내장 한국어 TTS(AVSpeechSynthesizer) 폴백, Kokoro는 영어·일본어. **개발 첫 주 한국어 샘플 검증 필수.**
2. **iOS 알람 신뢰성:** 백그라운드·무음·집중 모드에서 울리는지(AlarmKit 가능 범위) 실기기 검증.
3. **모델 용량(~80MB+)** 첫 다운로드 UX.
4. **입력 방식별 플랫폼 제약:** 클립보드는 사용자 붙여넣기 동작 필요, 카카오톡은 공유 시트 경유만 가능.
5. 경쟁 앱 존재 → "내 목소리 + 오프라인 + 사운드 연출 + 입력 마찰 제로"로 포지셔닝.

## 10. 수익 모델
무료(알람 1~3개, 기본 배경음, 공유 등록) / 프리미엄 월 2,900원 또는 평생 19,000원(배경음 팩, 무제한 알람·목소리, 캘린더 구독, 위젯·워치, 음성 메시지). 광고 없음(수면 직후 경험 보호).

## 11. 개발 일정
- 1~2주: Kokoro 한국어 검증, AlarmKit 알람 신뢰성 + 오디오 믹스 프로토타입
- 3~6주: MVP
- 7~10주: v1.1 (공유 시트, 캘린더, 위젯) → TestFlight 베타
- 이후: v1.2 → Watch/v2
